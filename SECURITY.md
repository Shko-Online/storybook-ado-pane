# Security policy

## Supported versions

Only the latest version of the extension on the Visual Studio Marketplace receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's vulnerability reporting](https://github.com/Shko-Online/storybook-ado-pane/security/advisories/new)
(the **Report a vulnerability** button on the Security tab of this repository).

Include what you found, how to reproduce it and which version you used. We will acknowledge the
report, keep you updated while we work on a fix, and credit you in the advisory unless you prefer
otherwise.
